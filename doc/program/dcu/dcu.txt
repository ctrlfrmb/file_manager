1. 电源连接：
   - 12V正极 → R6 (B1+/B2+)
   - 12V负极 → R5 (PGND)
   - IGN信号 → R23 (可选，用于模拟点火状态)

2. CAN总线连接：
   - CAN适配器CAN_H → L27 (DCUCANH)
   - CAN适配器CAN_L → L19 (DCUCANL)
   - 确保120Ω终端电阻

3. LIN总线连接：
   - LIN适配器信号线 → R7 或 L21
   - 需要1kΩ上拉电阻到12V

# 发送网络管理唤醒报文
# 通常NM报文ID范围在0x400-0x4FF之间
网络管理帧范围: 0x400-0x4FF
├── FLDCU: 0x469 (网络管理帧)
├── RLDCU: 0x46B (网络管理帧)  
├── BCM: 0x409 (可能的唤醒源)
├── XCU: 0x429 (可能的唤醒源)
└── 其他ECU: 0x4XX (各ECU网络管理帧)
